# Data Governance README

This document provides an overview of data governance in the dbt-clickhouse-lab project.

## Components

### 1. Data Owners
- Defined in `docs/DATA_OWNERS.md`
- Each data asset has an owner responsible for quality, documentation, and access control

### 2. Access Control
- Defined in `docs/ACCESS_CONTROL.md`
- Role-based access control with analyst, data_engineer, data_owner, and admin roles

### 3. Audit
- Defined in `docs/AUDIT.md`
- Tracks all data modifications, access, and schema changes

### 4. Metadata
- Defined in `docs/METADATA.md`
- Model metadata includes owner, classification, and data quality information

## Usage

1. Review `docs/DATA_GOVERNANCE.md` for an overview
2. Check `docs/DATA_OWNERS.md` for ownership structure
3. Review `docs/ACCESS_CONTROL.md` for access control
4. Check `docs/AUDIT.md` for audit information
5. Review `docs/METADATA.md` for metadata configuration
