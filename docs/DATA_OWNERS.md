# Data Owners

This document describes data ownership structure for the dbt-clickhouse-lab project.

## Ownership Model

Each data asset is owned by a specific team or individual responsible for:

- Data quality and accuracy
- Documentation updates
- Access control requests
- Breaking change management

## Data Owners

| Domain | Owner | Contact | Scope |
|--------|-------|---------|-------|
| Customer | Analytics Team | analytics@company.com | All customer-related data |
| Orders | Analytics Team | analytics@company.com | All order-related data |
| Parts | Analytics Team | analytics@company.com | All part-related data |
| Suppliers | Analytics Team | analytics@company.com | All supplier-related data |
| Line Items | Analytics Team | analytics@company.com | All lineitem-related data |

## Owner Responsibilities

### Data Quality
- Monitor data quality metrics
- Address data anomalies
- Approve model changes

### Documentation
- Ensure model documentation is up-to-date
- Review changes to data definitions
- Maintain business glossary entries

### Access Control
- Approve access requests for sensitive data
- Define data classification levels
- Review access control policies

## Contact

For questions about data ownership, contact the Analytics Team at analytics@company.com.
